INTRODUCTION                                                             *ack*

This plugin is a front for search tools like ripgrep (rg), the_silver_searcher
(ag), and ack.  These tools can be used as replacements for grep.  This plugin
will allow you to run these search tools from vim, and shows the results in a
split window.

The plugin automatically detects and uses the first available tool in this
order: ripgrep (rg), the_silver_searcher (ag), ack, or ack-grep.

:Ack[!] [options] {pattern} [{directory}]                               *:Ack*

    Search recursively in {directory} (which defaults to the current
    directory) for the {pattern}.  Behaves just like the |:grep| command, but
    will open the |Quickfix| window for you. If [!] is not given the first
    error is jumped to.

:AckAdd [options] {pattern} [{directory}]                            *:AckAdd*

    Just like |:Ack|, but instead of making a new list, the matches are
    appended to the current |quickfix| list.

:AckFromSearch [{directory}]                                  *:AckFromSearch*

    Just like |:Ack| but the pattern is from previous search.

:LAck [options] {pattern} [{directory}]                                *:LAck*

    Just like |:Ack| but instead of the |quickfix| list, matches are placed in
    the current |location-list|.

:LAckAdd [options] {pattern} [{directory}]                          *:LAckAdd*

    Just like |:AckAdd| but instead of the |quickfix| list, matches are added
    to the current |location-list|

:AckFile [options] {pattern} [{directory}]                          *:AckFile*

    Search recursively in {directory} (which defaults to the current
    directory) for filenames matching the {pattern}.  Behaves just like the
    |:grep| command, but will open the |Quickfix| window for you.

:AckHelp[!] [options] {pattern}                                      *:AckHelp*

    Search vim documentation files for the {pattern}.  Behaves just like the 
    |:Ack| command, but searches only vim documentation .txt files

:LAckHelp [options] {pattern}                                        *:LAckHelp*

    Just like |:AckHelp| but instead of the |quickfix| list, matches are placed
    in the current |location-list|.

Files containing the search term will be listed in the split window, along
with the line number of the occurrence, once for each occurrence.  <Enter> on
a line in this window will open the file, and place the cursor on the matching
line.

See http://betterthangrep.com/ for more information.

==============================================================================
MAPPINGS                                                        *ack-mappings*

The following keyboard shortcuts are available in the quickfix window:

o                   open file (same as enter).

go                  preview file (open but maintain focus on ack.vim results).

t                   open in a new tab.

T                   open in new tab silently.

h                   open in horizontal split.

H                  open in horizontal split silently.

v                   open in vertical split.

gv                  open in vertical split silently.

q                   close the quickfix window.

==============================================================================
CONFIGURATION                                              *ack-configuration*

The plugin can be configured using Lua:

>lua
    require('ack').setup({
        -- Location of the search utility (auto-detects rg, ag, ack, or ack-grep)
        ackprg = nil,  -- e.g., "rg --vimgrep" or "ag --vimgrep"
        
        -- Apply quickfix mappings
        apply_qmappings = true,
        
        -- Apply location list mappings  
        apply_lmappings = true,
        
        -- Quickfix handler
        qhandler = "copen",
        
        -- Location list handler
        lhandler = "lopen",
        
        -- Show search notifications
        show_notifications = false,
        
        -- Window picker configuration
        window_picker = {
            enable = true,
            chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZ",
            highlight = "StatusLine:AckWindowPicker,StatusLineNC:AckWindowPicker",
            exclude = {
                filetype = { "notify", "packer", "diff", "fugitive", "fugitiveblame", 
                            "NvimTree", "neo-tree" },
                buftype = { "terminal", "help", "prompt" }
            }
        }
    })
<

The plugin automatically detects the best available search tool:
- ripgrep (rg) - fastest, with gitignore support by default
- the_silver_searcher (ag) - fast alternative to ack
- ack or ack-grep - the original Perl-based tool
